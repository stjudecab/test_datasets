# test_datasets

Test data used in github actions for stjudecab's cab-LR-fusion pipeline

## Test dataset

This test dataset is composed of:

- `samplesheet_nanopore.csv`: samplesheet used for testing the data from ONT platform.
- `samplesheet_pacbio.csv`: samplesheet used for testing the data from Pacbio platform.
- `nanopore/*.fastq.gz`: The testing subreads of Nanopore data.
- `pacbio/alz.1perc.subreads.10000.bam`: The testing subreads of Pacbio data.
