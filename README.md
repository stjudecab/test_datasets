# test_datasets: ont-basecall

This branch contains test data to be used for automated testing with the [stjudecab/ont-10xrnaseq-basecall](https://github.com/stjudecab/ont-10xrnaseq-basecall) pipeline.

## Basecalling test data

### Files

#### Test Sample Sheet
- `test_basecall.csv` - test DNA sample information
- `test_basecall_sc.csv` - test 10X single-cell sample information

#### Test Pod5/Fast5 Data
- `pod5` - test data in `pod5` format for basecalling testing.
- `fast5` - test data in `fast5` format for basecalling testing.
- `10X` - test data in `pod5` format for testing `10xscrna` protocol.
